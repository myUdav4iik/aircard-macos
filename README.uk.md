# AirCard macOS

[English](README.md) · **Українська** · [Polski](README.pl.md)

Нативний порт для macOS процесу зміни дизайну карток Apple Wallet з [AirCard-Windows](https://github.com/Lumid-Off/AirCard-Windows). Інтерфейс написано на Swift 6.2 зі Swift Concurrency для виявлення iPhone, підготовки зображень та атомарного запису.

> Статус: перевірено на iPhone18,3 з iOS 27.2 (збірка 24B5084k). Виявлення хешу картки також підтримує iOS 18 (зокрема 18.7.8). Проєкт використовує приватні API Apple, є експериментальним і не є офіційним інструментом Apple.

## Мови

Застосунок використовує мову macOS (Системні параметри → Загальні → Мова й регіон). Підтримуються: англійська (`en`), українська (`uk`), польська (`pl`). Бразильська португальська (`pt-BR`) очікує оновлення і поки показує англійський текст.

Щоб примусово запустити українською:

```sh
open build/AirCardMac.app --args -AppleLanguages '(uk)'
```

## Встановлення та збірка

Найпростіше — завантажити `AirCardMac.dmg` зі сторінки релізів, відкрити його й перетягнути `AirCardMac.app` у «Програми». Застосунок підписано ad-hoc, тому під час першого запуску клацніть правою кнопкою → **Відкрити** (або дозвольте запуск у Системні параметри → Конфіденційність і безпека).

Зібрати самостійно (потрібні Command Line Tools):

```sh
chmod +x Scripts/*.sh
Scripts/build_dmg.sh
open build/AirCardMac.dmg
```

DMG містить універсальний `AirCardMac.app` для Apple Silicon та Intel.

## Як змінити зображення картки

1. **Підготуйте iPhone:** підключіть його кабелем USB, розблокуйте й натисніть **Довіряти**. Один раз відкрийте **Apple Books** на iPhone (застосунок використовує його канал синхронізації для запису файлів).
2. **Знайдіть картку:** на бічній панелі натисніть **Виявити з Wallet**. На iPhone відкрийте **Wallet** і торкніться потрібної картки. Вона з’явиться в розділі **Картки**. Клацніть правою кнопкою → **Використати як ціль** (або залиште ввімкненим «Стежити за останньою відкритою карткою»).
3. **Створіть дизайн:** відкрийте **Студію карток**. Натисніть **Додати зображення** й виберіть картинку (або перетягніть її на картку), чи виберіть один із готових **Стилів**. Налаштуйте розміщення та ефекти в **Інспекторі**. Увімкніть **Зони Wallet**, щоб бачити, яку частину видно в стосі карток.
4. **Застосуйте:** переконайтеся, що в меню карток на панелі інструментів вибрано потрібну картку, і натисніть **Застосувати**. Тримайте iPhone розблокованим з увімкненим екраном, доки журнал **Активність** не повідомить про завершення.
5. **Перевірте результат:** примусово закрийте Wallet на iPhone (змахніть його в перемикачі програм) і відкрийте знову.

Поради:

- Рекомендований розмір зображення — **1536 × 969** (пропорції картки). Інші розміри масштабуються відповідно до вибраного режиму вписування.
- Кожен застосований дизайн зберігається в **Історії застосованих скінів** картки — його можна відкрити в студії або застосувати знову.
- **Щоб повернути оригінальний дизайн банку,** видаліть картку з Wallet і додайте її знову. Застосунок не може прочитати чи зберегти оригінальне зображення.
- Якщо нічого не змінилося, заблокуйте й розблокуйте iPhone, знову відкрийте Wallet і перевірте журнал **Активність** на помилки.

## Студія карток

- Шари: зображення, колір, лінійний/радіальний/конічний градієнт, сітчастий градієнт, голографія, шліфований метал, блиск, зернистість, візерунки (лінії, крапки, сітка, карбон, гільош, хвилі) і текст.
- Для кожного шару — непрозорість і режим накладання, а також глобальна корекція кольору, віньєтка, світіння, розмиття й різкість.
- Готові стилі: Титан, Голо, Аврора, Карбон, Гільош, Скло, Захід сонця, Нуар.
- Перетягуйте картку, щоб нахилити її й побачити відблиски. Wallet отримує статичне зображення, тому «Нахил» визначає зафіксований кут експорту.
- Скасування/повтор, збереження й відкриття `.aircardskin`, імпорт зображень перетягуванням.
- Застосовані скіни зберігаються в `~/Library/Application Support/AirCard/Cards/<hash>/`.

## Обмеження

- **Неможливо прочитати поточне зображення картки у Wallet** — дані Wallet недоступні через AFC, а AirTraffic підтримує лише запис.
- Тому **резервної копії оригінального дизайну немає**. Щоб повернути оригінал, видаліть картку з Wallet і додайте знову.
- Ефекти руху/гіроскопа малює iOS; записане зображення залишається статичним.

Технічні подробиці (формат `.passthm`, колір цифр клавіатури, кеші TelephonyUI) — в [англійському README](README.md).
